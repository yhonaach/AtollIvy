# AtollIvy

Turns simple SQL reports into interactive dashboards for data analysts and business users without coding expertise.

AtollIvy is aimed at developers who need a straightforward, dependable solution.

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/AtollIvy.git`
2. `cd AtollIvy`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure AtollIvy, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
